# 随手记

$ARGUMENTS

自由捕获。用户说了任何内容，自动判断类型并写入对应子目录：

| 用户说的类型 | 写入位置 |
|-------------|---------|
| 想法/灵感/观点/感悟 | `02.笔记/灵感想法/` |
| 学习/看书/上课笔记 | `02.笔记/学习笔记/` |
| 开会/沟通/讨论 | `02.笔记/会议记录/` |
| 任务/待办/今天要干 | `01.每日工作台/今日任务/` |
| 好文章/外部内容 | `03.素材库/文章收藏/` |
| 金句/语录 | `03.素材库/金句语录/` |
| 案例参考 | `03.素材库/案例参考/` |
| 项目/进度 | `04.业务/项目管理/` |
| 客户/沟通记录 | `04.业务/客户档案/` |
| 收入/支出/记账 | `04.业务/财务记录/` |
| 日记/心情 | `05.个人/日记感悟/` |
| 目标/复盘/习惯 | `05.个人/目标计划/` |
| 运动/健康/体重 | `05.个人/健康记录/` |

不确定时放 `02.笔记/灵感想法/`，后续整理。

写入时：
- 自动命名（根据内容提炼关键词）
- 加 YAML frontmatter（tags + date）
- 至少链接到一个已有笔记（防孤儿）
