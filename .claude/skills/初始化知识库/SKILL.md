# 初始化知识库

## 触发条件

- 用户说"开始使用""开始使用知识库""初始化""第一次用"
- 或 SessionStart Hook 检测到 `brain/North Star.md` 为空模板时主动提示

## 流程

### 第一步：问名字

"你叫什么名字？"

等用户回答，记住名字，后续所有称呼用这个名字。

### 第二步：给场景选项

"你主要用知识库做什么？可以多选。"

给用户以下选项（用 AskUserQuestion 工具）：

| 选项 | 说明 |
|------|------|
| 内容创作 | 自媒体、短视频、公众号、小红书等 |
| 学习提升 | 学生、考研、考证、技能学习 |
| 业务管理 | 创业、副业、团队管理、客户管理 |
| 生活记录 | 日记、个人成长、家庭、健康 |
| 多场景混合 | 以上几个都要 |

### 第三步：根据选择追问

根据用户选择的场景，追问 1-2 个关键问题：

**内容创作**：
- 你在哪些平台发布？（公众号/视频号/抖音/小红书/其他）
- 你的内容方向是什么？

**学习提升**：
- 你在学什么？（学校课程/考研/考证/职业技能/兴趣）
- 你是什么阶段？（小学/初中/高中/大学/已工作）

**业务管理**：
- 你做什么业务？（产品/服务/电商/内容/其他）
- 你是个人还是有团队？

**生活记录**：
- 你想记录什么？（日记/成长/家庭/健康/读书/其他）

**多场景混合**：先问以上哪个最重要，再问对应问题。

### 第四步：生成定制结构

根据用户回答，做以下事情：

#### 4.1 填充 North Star.md

把用户的回答整理成：
- 我是谁：名字 + 身份
- 我的目标：用户想做什么
- 我不做什么：根据用户没选的场景推断

#### 4.2 创建场景专属目录

**注意：通用子目录已预置（01~05 及其子目录），只需创建场景专属目录（06.起）。**

根据用户选择的场景，在 Vault 根目录追加对应目录：

**内容创作追加：**
```
06.选题/        — 选题库、选题排期
07.文案/        — 文案草稿、成品
08.发布存档/    — 已发布内容归档
09.数据反馈/    — 发布数据记录
```

**学习提升追加：**
```
06.课程/        — 课程笔记、学习材料
07.复习/        — 知识卡片、错题、复习计划
```

**业务管理追加：**
```
06.项目/        — 项目文档、进度
07.客户/        — 客户记录、沟通历史
```

**生活记录追加：**
```
06.日记/        — 每日记录
07.目标/        — 年度目标、月度复盘
```

#### 4.3 每个新目录创建 README.md

每个新创建的场景目录放一个简短 README，说明：
- 这个目录放什么
- 怎么用
- 举例

（通用子目录的 README 已预置，不需要重复创建。）

#### 4.4 确认完成

向用户报告：
"{名字}，你的知识库已就绪。"

简要说明：
- 创建了哪些目录
- 每个目录放什么
- 可以开始了

### 注意事项

- 不要一次问太多问题，最多 2 轮对话完成初始化
- 用户回答不完整也没关系，先用已有信息生成，后面随时可以改
- 目录命名用中文 + 序号，保持清晰
- 所有文件用中文
- 初始化完成后，后续使用中 AI 根据对话内容持续补充 North Star 和记忆文件
