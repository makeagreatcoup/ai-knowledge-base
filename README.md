# AI 知识库

> 个人 AI 知识库 — 灵感、笔记、素材、业务、生活，一站管理。

## 快速开始

### 前置条件

- [Obsidian](https://obsidian.md/) 已安装
- [Claude Code](https://claude.ai/code) 已安装
- Node.js 22+（用于 Hook 脚本）

### 3 步开始

1. **Clone 仓库**

```bash
git clone <仓库地址> my-knowledge-base
```

2. **用 Obsidian 打开**

打开 Obsidian → 打开文件夹 → 选择 `my-knowledge-base`

3. **启动 Claude Code 并说"开始使用"**

```bash
cd my-knowledge-base
claude
```

然后在对话里说：**开始使用**

AI 会问你几个问题，根据你的回答自动配置知识库。

## 知识库结构

### 通用目录（所有人都有）

| 目录 | 子目录 | 放什么 |
|------|--------|--------|
| `01.每日工作台/` | `今日任务/` `本周计划/` | 今天要干的事、周计划复盘 |
| `02.笔记/` | `灵感想法/` `学习笔记/` `会议记录/` | 想法、学习、开会记录 |
| `03.素材库/` | `文章收藏/` `金句语录/` `案例参考/` | 外部好内容 |
| `04.业务/` | `项目管理/` `客户档案/` `财务记录/` | 工作、项目、客户、财务 |
| `05.个人/` | `日记感悟/` `目标计划/` `健康记录/` | 生活、成长、健康 |
| `brain/` | — | AI 记忆层（目标、决策、模式） |

### 场景目录（初始化时根据选择自动创建）

| 场景 | 追加目录 |
|------|---------|
| 内容创作 | 选题 / 文案 / 发布存档 / 数据反馈 |
| 学习提升 | 课程 / 复习 |
| 业务管理 | 项目 / 客户 |
| 生活记录 | 日记 / 目标 |

## 对 AI 说什么

| 你说 | AI 写入 |
|------|---------|
| "开始使用" | 初始化知识库 |
| "有个想法…" | `02.笔记/灵感想法/` |
| "记下学习笔记…" | `02.笔记/学习笔记/` |
| "今天要干…" | `01.每日工作台/今日任务/` |
| "存一下这篇好文章…" | `03.素材库/文章收藏/` |
| "存个金句…" | `03.素材库/金句语录/` |
| "新项目…" | `04.业务/项目管理/` |
| "记一笔收入…" | `04.业务/财务记录/` |
| "写个日记…" | `05.个人/日记感悟/` |
| "帮我找…" | 语义搜索全库 |

| `/ka-wrap` | 会话收尾 |
| `/ka-search` | 语义搜索 |
| `/ka-audit` | 知识库体检 |
