# 内容知识库模板（LLM Wiki 版）

基于 Karpathy 的 LLM Wiki 范式搭建的内容知识库模板。

给 AI 一份长期维护的工作，把你的原声编译成一座会生长的 wiki，再由它反哺你的内容产出。

## 它解决什么问题

大多数 AI 写作不像你，是因为你的库里装满了别人的框架，你的原话只是原料。AI 天天泡在别人的结构里，写出来自然像别人。

这个模板反过来：`raw/我/` 是你的原声，逐字不改，只读。所有 wiki 页只能从它提炼，写稿只能从它取句子。

## 目录

- `raw/我/`：原声（灵感、口播、咨询、聊天），只读
- `raw/外部/`：剪藏、对标、课程，只供结构参考
- `wiki/`：sources / concepts / entities / topics 四类页面，AI 全权维护
- `生产/`：成稿与发布后数据
- `日志/`：每次维护的变更记录，只追加

## 怎么开始

1. 复制这个仓库，用 Obsidian 打开
2. 填 `wiki/entities/示例-我.md`，改名为 `我.md`
3. 把原声素材丢进 `raw/我/`，不用整理
4. 对 AI 说「入库」，它会编译 source 页并更新 wiki
5. 说「给我选题」，它从 `wiki/topics/` 里挑，或新建一个带原声引用的 topic
6. 说「写这一篇」，它先读「你」那一页，再动笔

规则全在 `CLAUDE.md`。
